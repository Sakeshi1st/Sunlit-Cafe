# Sunlit Cafe ☼

A responsive, warm-toned cafe landing page built with plain HTML, CSS, and JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- Accessible mobile navigation and keyboard focus styles
- Hero section, story, sample menu, quote, visit details, and footer
- Reduced-motion support
- No build tools, packages, or framework required

## Run locally

Open `index.html` in a browser. Alternatively, run a local server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for the Pages build to finish. GitHub will show the published URL in Pages settings.

## Customise before publishing

- Replace the sample address, opening hours, email, menu items, and prices in `index.html`.
- Replace the Unsplash photo URLs with your own licensed cafe photography if desired.
- Update the page title and description in the `<head>` section.
- The menu, address, hours, and contact details are demo content, not verified business information.
